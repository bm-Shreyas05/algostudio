Terms of Use

Last updated 16 September 2026

The short version. This is a free student project shown publicly for educational purposes. It may be slow, may be offline, and may delete your recordings after fourteen days. Use it to learn. Do not rely on it for anything that matters, and do not attack it.

1. What this service is

AlgoStudio is a free, open-source educational demonstration of an event-driven program execution and visualization engine, published as a final-year engineering project. It is offered at no charge, with no contract, no account and no commercial relationship of any kind. By using it you accept these terms; if you do not accept them, please do not use it.

2. Availability

The service runs on free hosting. It may be slow to wake, unavailable without notice, reset without warning, or withdrawn permanently. There is no uptime commitment and no support obligation. Recordings are deleted automatically after fourteen days, and may be lost sooner when the server restarts.

Treat anything you produce here as temporary. If you need it to persist, run the project yourself — that is what the open-source release is for.

3. Acceptable use

Please do not:

  • attempt to escape, disable, or probe for weaknesses in the execution sandbox, or otherwise attack the host — except as described in section 4, which invites exactly that, responsibly;
  • use automated tools to generate load beyond ordinary interactive use, or attempt to circumvent the rate limits;
  • use the service to process personal data belonging to other people, or anything confidential, regulated or sensitive;
  • attempt to use it for unlawful purposes, or in a way that would harm other users or the hosting provider.

The public deployment does not accept code you write: it runs only the algorithms it ships with. Where you run an installation that does accept your code, you are responsible for what that code does.

4. Security research

Security reports are genuinely welcome, and the threat model is published rather than hidden. If you find a way past the sandbox or any other weakness, please report it privately through GitHub's security advisories for the repository, or open an issue if it is not sensitive. Please do not run denial-of-service tests against the hosted instance — it is a free tier shared with other projects. Test destructive scenarios against your own local copy.

6. The software

The AlgoStudio source code is published on GitHub and your use of the code is governed by the licence stated in that repository, not by this page. These terms cover only your use of this hosted demonstration.

7. Accuracy, and the limits of it

AlgoStudio is a teaching tool. Its correctness is checked by harnesses published with the source — instrumented programs are compared against native Python execution, and the time-travel invariants are verified across the fixture corpus — but it supports a documented subset of Python and it can be wrong. Explanations generated by the tutor panel are derived from the recorded execution and may still mislead.

Do not rely on this service for coursework you cannot check, for assessment, or for any decision with consequences. Verify against a real Python interpreter.
